# 💰 SpendWise Dashboard

> **A clean and modern dashboard for viewing and organizing personal spending.**

SpendWise is a responsive budget dashboard designed to give users a simple and organized view of their spending categories. This project focuses on creating a professional dashboard layout using **HTML and CSS**, with no JavaScript functionality.

## ✨ Features

- 📊 Clean dashboard layout
- 🧭 Sidebar navigation
- 👤 User profile section
- 💳 Six spending category cards
- 📱 Responsive design for smaller screens
- 🎨 Custom color palette using CSS variables
- ✨ Hover and keyboard focus effects
- 🌙 Dark theme support

## 📂 Dashboard Sections

### 🧭 Sidebar

The sidebar provides easy navigation to different sections:

- Dashboard
- Expenses
- Reports
- Savings
- Settings

### 👋 Dashboard Header

The header contains:

- Dashboard title
- Short welcome message
- User profile and icon

### 💳 Category Cards

The dashboard includes six main spending categories:

| Category         | Purpose                      |
| ---------------- | ---------------------------- |
| 🍔 Food          | Track food spending          |
| 🚗 Transport     | Track transportation costs   |
| 🏠 Rent          | Track housing expenses       |
| 🎬 Entertainment | Track entertainment spending |
| 💰 Savings       | Monitor savings              |
| 💡 Utilities     | Track utility expenses       |

## 🎨 Design

The dashboard uses a modern green-based color palette to create a clean and professional appearance.

CSS custom properties are used to manage the main colors, making the design easier to maintain and customize.

## 🧩 CSS Layout

### CSS Grid

CSS Grid is used for the main dashboard structure, including the:

- Sidebar
- Main content area
- Category card layout

### Flexbox

Flexbox is used inside different sections for:

- Sidebar navigation
- Header content
- Category cards
- Icons and text alignment

## 📱 Responsive Design

The dashboard is designed to work on different screen sizes.

On screens smaller than **768px**, the layout changes into a single-column design so that the content is easier to view on tablets and mobile devices.

## ✨ Interactive Design

Although the project does not use JavaScript, CSS interactions are included:

- Card hover effects
- Keyboard focus effects
- Smooth transitions
- Subtle movement and shadows

These effects make the dashboard feel more interactive and modern.

## 🌙 Dark Theme

A dark theme is supported using:

```css
@media (prefers-color-scheme: dark);
```

The dark theme changes the CSS variables while keeping the same HTML structure.

## 🛠️ Technologies Used

- **HTML5**
- **CSS3**
- **CSS Grid**
- **Flexbox**
- **CSS Custom Properties**
- **Responsive Design**
- **Media Queries**
